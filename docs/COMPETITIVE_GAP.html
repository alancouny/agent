你的差异化优势（竞品没有，应放大）

1. 一等公民 Hook 系统 — beforeRun / beforeModelCall / beforeToolCall 可 abort 短路、modify 改写上下文，支持多 hook 串联。OpenClaw 只有"插件"，CherryStudio 没有。这是工程级的可编程拦截能力，适合做"企业级安全闸门"（如拦截 rm -rf）。
2. MCP 工具直接并入 agent 同一注册表 — agent 真能调用 MCP 工具，且带审批 + 自动重连。CherryStudio 的 MCP 偏"配置展示"，你的更"活"。
3. Terminal / Workspace 是 agent 可调用的真实工具 — run_command + list_files 与 read_file/write_file 构成"文件系统+终端闭环"，本地自主执行比 OpenClaw 的"浏览器自动化"更可控。
4. 自托管、零遥测、全控制 — 数据都在你机器上的 SQLite，无第三方服务器。

差距清单（按优先级）

P0功能差距（用户最期待）

1. 知识库 / RAG — CherryStudio 的招牌功能。你完全没有文档摄取 / 切分 / 向量检索。建议接本地向量（sqlite-vec 或 chromadb），把已有 memories 表升格为"可检索知识库"，复用 loadMemories() 注入点。
2. 多模型广度 + 故障转移 + 并排对比 — 架构已支持 OpenAI 兼容，加 failover（主模型超时自动切备用）和"同消息多模型对比"改动小，但体验提升大。
3. 对话分支 / 全文检索 / token 计数 — 你现在只有会话持久化 + 恢复。加分支（在任意消息 fork）和 token 显示是 CherryStudio/OpenClaw 的基础体验。

P1产品化差距

4. 打包分发 — 你现在是 vite + tsx dev-server。没有安装包，"桌面 agent"只是开发者玩具。用 Tauri（轻量）或 Electron 封装，否则无法分发。
5. 提示词管理 — 变量 / 版本 / 团队共享。你目前 system prompt 硬编码 + skills 种子。
6. 语音 TTS / STT — CherryStudio 有。你已有图像生成 + OCR，语音是自然的下一步。

P2集成 / 体验

7. 消息渠道（微信/飞书/Telegram…）— OpenClaw 杀手锏，你没有。
8. 全局快捷键 / 系统托盘 / 浏览器扩展 — OpenClaw 深度 OS 集成，你没有。
9. 技能市场 / 社区 — OpenClaw ClawHub 3,286+。你只有手动种子 skills，无导入/导出/市场。
10. 可观测性看板（成本/token/日志/定时任务）— OpenClaw AEGIS 有。你零可观测。
11. Mermaid / Artifact 渲染 — 聊天里没有图表 / 交互式 HTML 沙盒。
12. 定时任务 / Cron — 无 agent 级调度（系统层的 automation 框架是另一回事）。

建议对标路线

  • 最短路径补齐 RAG：接 sqlite-vec，加 /api/knowledge（import PDF/MD → 切分 → 嵌入 → 检索），把 loadMemories() 扩成 loadContext()。这是和 CherryStudio 对齐的最大单点。
  • 把 Hook 做成卖点：可视化 Hook 编辑器（你已有结构化 config），竞品没有——这是差异化的护城河，不是追平项。
  • 加 failover + 模型对比：架构友好，改动小，体验提升大。
  • Tauri 打包：否则永远只是 demo。
  • 优先级建议：P0-1（RAG）→ P0-2（failover/对比）→ P1-4（打包）→ 同时持续放大 Hook 卖点。
